Accent as text on window: 4.8 : 1 Light. White on accent: 5.2 : 1

A bowerbird’s green-teal. It reads as “selected / here” without colliding with the system blue that NSMenu, focus rings in standard controls and links already use, and it is clearly not purple. Bower uses it only for state: the current layout, a hovered or focused wedge, toggles that are on, the snap preview and the primary button. Plain decoration stays neutral.
